# Security

Please report in-scope security issues privately via GitHub.

The report should include:

1. Summary of issue explained in plain language
2. Any unique conditions that must be set beyond the default configuration
3. Procedure to replicate the issue

## Security issues in scope

Issues that meet all of the following criteria are considered in scope:

- Sandbox mode is enabled within MIKE
- The issue occurs when the attacker does not previously have access to the application's configuration
