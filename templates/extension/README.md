# {{NAME}}

An extension for [MIKE](https://getmike.dev), written by an agent on this machine.

Nothing is built, bundled or installed on the way: `manifest.json` at this root says what the
extension is. Press **Try Extension** on a task to load that task's files, then refresh the tab — and
press again after any edit, because a refresh alone shows the last load's bytes.

Start by reading `AGENTS.md`, then the `extension-authoring` skill under `.agents/skills/`. The
skill decides the extension's type from what it is for, and `references/manifest.md` is the whole
manifest grammar.
